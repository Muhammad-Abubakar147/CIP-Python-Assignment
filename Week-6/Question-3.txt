Peek at the Record
Add a peek command that prints everything your program has saved in messages.



To implement this, follow these steps:

Make a constant INDENT = "    " (four spaces) at the top of your file.

Write a function peek(messages) that prints how many messages are in the list, then each message's role and content. Start every line it prints with INDENT, for example print(f"{INDENT}The record has {len(messages)} messages:").

In main, when the user types peek, call peek(messages) instead of sending anything to call_gpt. Do not add peek to messages.
