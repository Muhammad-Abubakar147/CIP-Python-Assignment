## About the Repository

This repository documents my complete learning journey through Stanford University's **Code in Place** program. It brings together the weekly Python programming questions and assignments provided by Code in Place, along with my own solutions.

The repository is organized week by week. Each week has its own folder, so the work can be explored in the same order the course was taught, or any single week can be reviewed on its own.

**How to explore this repository**
1. Open the [Weekly Learning Roadmap](#weekly-learning-roadmap) and choose a week.
2. Read the assignment questions inside that week's folder.
3. Review my Python solution and the approach behind it.
> [!NOTE]
> The assignment questions are created and provided by Stanford Code in Place and are included here for context. The solutions are my own work. This is a personal learning repository and is not an official Stanford University resource.
>
> If you are currently taking a course, please follow its academic integrity guidelines and use this repository for reference and learning rather than copying.

## About Stanford Code in Place

Code in Place is a free online programming course offered by Stanford University. It introduces the fundamentals of programming using Python, guiding learners through lessons and hands-on programming assignments that build problem-solving skills step by step.

Participation in the program is documented here as a learning experience. This repository does not represent a degree, university credit, or certification.

## Learning Philosophy

- **Consistency over intensity.** Steady, regular practice builds lasting skill more reliably than occasional bursts of effort.
- **Practical learning.** Concepts only become clear when applied, so every idea is reinforced by writing real code.
- **Independent problem-solving.** I attempt each problem on my own first, reasoning through the logic before looking for outside help.
- **Continuous improvement.** Every solution is a chance to refine readability, structure, and efficiency.
